# Charles Tare Booc — Student Portfolio

A responsive student portfolio built with plain HTML, CSS, and JavaScript, designed for GitHub Pages.

## Files
- `index.html` — page content and sections
- `style.css` — responsive styling, visual effects, light/dark theme
- `script.js` — mobile menu, theme toggle, scroll progress, reveal effects, project modals, copy-email action
- `profile-hero.png` — portfolio hero artwork shown in the website

## Preview locally
Open `index.html` in a browser, or open the folder in Visual Studio Code and use the Live Preview extension.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `portfolio`.
2. Upload the contents of this folder (not just the ZIP). Keep `index.html`, `style.css`, `script.js`, and `profile-hero.png` at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then save.
6. Wait for the published link, then open it in a private/incognito window and on your phone.

The live address will typically look like `https://YOUR-USERNAME.github.io/portfolio/`.

## Personalize before submitting
- Confirm your name, course, location, and email are correct.
- Replace project descriptions with what you personally completed.
- Add real project screenshots and repository/demo links when available.
- If you want to show a resume, place a public PDF in the project and add a link to it.
- Test every link, the mobile menu, theme switch, project details, and email action.

## Notes
- The project cards use original CSS illustrations, not screenshots of finished apps.
- The contact button uses a `mailto:` link. It opens the visitor's configured email app; it does not send a message from the website itself.
- The Google Fonts connection is optional; system fallback fonts are included.

## Responsive layout
The layout adapts to desktop, tablet, and mobile screens. The hero portrait scales within its container, the navigation becomes a mobile menu, and project/skills sections switch to narrower layouts on small screens.
